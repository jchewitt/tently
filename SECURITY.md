# Security

Treat repository documents, model output and runtime traces as untrusted input.
Configure only sources appropriate for your extraction provider. Never include credentials,
environment files, customer data, account identifiers or private payloads in public fixtures.
Use local trusted adapters; adapter modules execute code.

Report potential security issues privately to the destination repository maintainers rather
than posting private inputs or credentials in public issues. A dedicated reporting channel
has not yet been configured.
